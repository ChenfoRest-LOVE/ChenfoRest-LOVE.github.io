# 文章评论与独立访客账号

用户已确认：采用独立账号注册/登录，先完成本地完整功能并由 GitHub 管理，备案后再上线。此次不连接腾讯云、不打开域名、不变更 DNS。

## 行为与界面

两篇文章正文与文章导航之间各有评论区。宽度沿用正文 680px（大屏 720px），小标题、细分隔线、纵向列表，无卡片或装饰图。沿用深浅主题变量与现有字体。只给交互状态使用短渐变，尊重减少动画设置。

未登录可阅读评论；账号由用户名和密码注册，注册成功自动登录。已有账号可登录、退出，登录在两篇文章之间共用。只显示用户名，不收集邮箱。密码不出现在日志、URL、Git 或浏览器存储。登录使用按需打开的原生 dialog，支持键盘与焦点返回。

登录后可提交纯文本评论；正文先 NFC 规范化、去除首尾空白，然后按 Unicode 码点计数，范围 1–100（汉字、标点、空格、换行和 emoji 的每个码点均计数）。前端显示计数，后端独立强制校验。禁止 HTML 渲染。用户可以删除自己的评论，不能删除他人的评论。每篇独立、最新在前，每页 20 条，可加载更早评论。提交成功后清空草稿；失败保留草稿并显示可操作错误。

## 架构与边界

静态 HTML/CSS/JS 继续由 GitHub Pages 托管。新增独立 `community/` Python 标准库后端和 SQLite，访客账号与封面管理员完全隔离。`articles.json` 为文章 ID 白名单。

本地 `community/start.ps1` 启动 loopback 4192，后端同时只读提供网站公开文件，覆写评论配置为启用。数据存放在用户本机 LOCALAPPDATA/ForestComments，位于仓库以外。静态配置默认禁用，GitHub Pages 显示“评论暂未开放”，不伪造数据、不请求未部署的接口。

未来上线采用同源 HTTPS 反向代理 `/api/community/`，仅需启用静态配置与部署后端；此次只提供文档与示例配置，不安装服务或同步腾讯云。暂不引入第三方账号、邮件、找回密码、回复、点赞、管理员删评、站内通知。

## 数据与防护

密码 scrypt（N=131072,r=8,p=1）随机 salt，最多两个并行哈希任务；用户名 3–32 位字母数字及 `_.-`、大小写不敏感唯一，密码 12–128 字符。会话有效期 8 小时，数据库只存会话哈希。生产 Cookie Secure/HttpOnly/SameSite=Strict，开发 Cookie 仅限本机 HTTP；写入同时验证 Host、Origin、JSON 与 CSRF。生产仅允许 HTTPS origin，服务始终只监听 127.0.0.1。请求大小、连接数量、超时有界。

注册/登录尝试和发评论限速写入 SQLite，重启不重置；IP 以 SHA256 摘要记录，仅信任明确开启的本机反代头。评论每用户 30 秒一条，IP 每小时 20 条。注册每 IP 每小时 5 次、全局 50 次；登录每 IP 每 15 分钟 10 次、全局 60 次。静态文件白名单拒绝数据库、脚本、配置和目录穿越。API 响应不缓存，日志不记录请求内容。数据库 POSIX 权限 600。

真实临时数据库单元与 HTTP 测试验证注册/登录/退出/会话过期、哈希、大小写唯一、跨用户删除拒绝、两个文章隔离、100/101 中文与 emoji 边界、空白/类型/控制字符拒绝、分页、限速重启保留、来源/CSRF/Host/请求体校验和静态文件范围。浏览器走完整两用户流程、刷新持久化、两篇共用登录、恶意文本安全呈现、移动端与浅色主题、静态禁用状态。旧后台与相册测试回归。审查后提交到 main 与 GitHub；腾讯云继续待同步。
